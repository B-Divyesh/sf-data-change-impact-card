Bundled CLI sandbox

Run sample lineage data.

Use one command to create a temporary folder with sample input and a generated impact card.

dcic demoor dcic --demo

The command never reads your project. It does not connect to production or run a job.

What the sample does

  1. Writes sample inputCreates lineage.yaml and changes.yaml in a unique temporary folder.
  2. Traces the changeFinds two stale assets from one version change in complete declared lineage.
  3. Prints the output pathWrites impact.md and prints its exact path for review.

Expected terminal result

Demo — bundled sample data; no production connection or job run.
Sample directory: /tmp/dcic-demo-…
Impact card: /tmp/dcic-demo-…/impact.md
Result: 2 stale assets, 7 known minutes, 0 unknown edges.

Open the printed file to inspect the Markdown card. Delete the temporary folder when you are done.
